CSS Usage

:root { /* Primary Colors */ --primary-color: #0b0b0b; --primary-light: #2d2d2d; /* Secondary Colors (Brand) */ --secondary-color: #8a6800; --secondary-dark: #5d4600; --secondary-light: #b88d00; /* Accent Colors */ --accent-color: #cc8800; --accent-light: #ffaa00; /* Status Colors */ --success-color: #5cb85c; --warning-color: #cc8800; --danger-color: #cc1111; --info-color: #5bc0de; /* Text Colors */ --text-dark: #0b0b0b; --text-color: #5d5d5d; --text-light: #8c8c8c; --text-white: #ffffff; /* Background Colors */ --background-color: #ffffff; --background-dark: #f5f5f5; --background-darker: #e8e8e8; }
📝 Notes: This color palette is inspired by OpenWrt 2020 theme and customized for Tirtayana branding. All colors are defined as CSS custom properties (variables) for easy customization and consistency across the theme.
✅ Accessibility: All color combinations meet WCAG 2.1 AA standards for contrast ratio. Dark text on light backgrounds and light text on dark backgrounds ensure readability.
