================================================================================
  LUCI THEME ARGON - TIRTAYANA CUSTOM EDITION
================================================================================

Custom LuCI theme untuk OpenWrt dengan branding Tirtayana
Palet warna terinspirasi dari OpenWrt 2020

--------------------------------------------------------------------------------
QUICK START
--------------------------------------------------------------------------------

1. Aktifkan tema di build:
   $ cd openwrt/package/luci-theme-argon-tirtayana
   $ ./enable-theme.sh
   $ cd ../..

2. Build package:
   $ make package/luci-theme-argon-tirtayana/compile V=s

3. Install di router:
   $ scp bin/packages/*/base/luci-theme-argon-tirtayana*.ipk root@192.168.1.1:/tmp/
   $ ssh root@192.168.1.1 'opkg install /tmp/luci-theme-argon-tirtayana*.ipk'

4. Tema otomatis aktif setelah instalasi!

CUSTOMIZATION
--------------------------------------------------------------------------------

Ganti Logo:
  cp your-logo.svg htdocs/luci-static/argon-tirtayana/logo.svg

Ubah Warna:
  edit htdocs/luci-static/argon-tirtayana/cascade.css
  # Ubah variable di bagian :root { }

COLOR PALETTE
--------------------------------------------------------------------------------

Primary:   #0b0b0b (Dark Black)  - Header, Navigation
Secondary: #8a6800 (Golden)      - Buttons, Links
Accent:    #cc8800 (Orange)      - Highlights, Warnings
Success:   #5cb85c (Green)       - Success messages
Danger:    #cc1111 (Red)         - Errors, Delete
Text:      #5d5d5d (Gray)        - Body text
Background:#ffffff (White)       - Main background
